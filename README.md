# Обновлённый Bot_Fox: получение кода без скачивания ZIP в браузере

## Все исходники открыты отдельными файлами

Откройте папку **[code](code)**. Там находятся Main.py, DataBase.py, ads.py, handlers.py, переводы, зависимости, инструкции и тесты.
Публичная папка содержит исходники и пустой образец настроек. Оригинальные ключи и базы пользователей находятся только в защищённом архиве.

## Если вообще не скачиваются файлы: копирование одного текстового файла

Откройте **[COPY_SOURCE.py](COPY_SOURCE.py)**, скопируйте ВЕСЬ текст кнопкой Copy raw file, сохраните на компьютере как `COPY_SOURCE.py` и выполните:

```powershell
py -3.11 COPY_SOURCE.py
```

Без сети и дополнительных пакетов появится `Bot_Fox_source` со всеми исходниками. Добавьте в эту папку свои исходные `admin.env`, `.env.env`, `DataBase.sql` и `ads.sqlite3`, которые были загружены в чат. При отсутствии баз приложение создаёт новые пустые базы.

## Полный проект вместе с ключами и базами — через Git

Установите Git и Python 3.11, затем выполните в PowerShell:

```powershell
git clone --depth 1 --branch codex/bot-fox-download-20261018 https://github.com/Farmander/Bot_Fox.git Bot_Fox_delivery
cd Bot_Fox_delivery
py -3.11 -m pip install pyzipper==0.3.6
py -3.11 restore_project.py
```

Введите пароль из чата (при вводе символы не отображаются). В папке `restored/Bot_Fox_updated` появится полный проект, включая сохранённые ключи и базы. Python восстанавливает архив сам — 7-Zip и ручное скачивание ZIP не нужны. Если папка результата уже существует, скрипт откажется её перезаписывать.

После восстановления читайте `README_RU.md`. Бот запускается через `Main.py` на Python 3.11. Ветка `Bot` не изменена.
